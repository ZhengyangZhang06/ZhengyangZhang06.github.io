How the tree works, in one paragraph

The frozen main theorem is the root obligation. prove sessions try to prove an obligation directly; dec sessions split it into child statements plus a glue proof of the parent from the children, which the trusted checker verifies against stubs before any child is proved; an aud session reviews every split before it is accepted. Proving and splitting race on the same obligation: if a direct proof lands first, the split's subtree is superseded (shown faded); if the split's children are all proved, the glue is re-checked and closes the parent. Only the checker's acceptance counts. A C session continues an earlier conversation, an S is a fresh one, an R a retry.
