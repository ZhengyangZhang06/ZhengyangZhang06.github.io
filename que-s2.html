S2：有限条闭测地线合起来也不超过 ½ − ε

原定理只管一条闭测地线。S2 证明：任取有限条闭测地线 γ1, …, γk，半经典测度放在它们提升的并集上的总质量也不超过 ½ − ε。

和原来比，进步在哪里

-- 定理 A（原来）：一条闭测地线
∀ γ, (本原闭测地线) → ∃ ε > 0, … → μ(Γ_γ) ≤ ½ − ε

-- S2：任意有限条闭测地线
∀ k, ∀ γ₁ … γ_k, (每条都是本原闭测地线) → ∃ ε > 0, … → μ(Γ_γ₁ ∪ … ∪ Γ_γk) ≤ ½ − ε

它排除了原定理管不到的"分散的半疤痕"，比如

½·Liouville + ¼·(γ1 上的测度) + ¼·(γ2 上的测度)

对单独每一条闭测地线，这个测度只放了 ¼ 的质量，原定理不会报警；但两条加起来是 ½，正好卡在旧的临界线上，本质上和原定理排除的半疤痕是同一类东西。这是读到定理 A 时最自然的一个追问，S2 直接回答它。

为什么应该成立

  • 抽象部分不受影响。证明的算子代数部分只区分"在管子里"和"在管子外"。把一条闭测地线的管子换成有限条的并，这部分一个字都不用改。
  • 管子不会重叠。两条不同的闭测地线在曲面上相交时方向不同，所以它们在 S*M 上的提升不相交；足够细的管子是不交的。
  • 要改的是几何部分。原证明在双曲平面的边界上计数一根"轴"（闭测地线对应的群元素）的平移。现在有 k 根轴：每次访问要选一根，计数常数多出一个 k 倍的因子。这个常数在取极限时消失，所以 ε 不受影响。

它不说明什么

  • 上界还是 ½ − ε，没有变小。
  • 只管有限条。所有闭测地线有可数无穷多条，它们的并在 S*M 中稠密，S2 不涉及。
  • 它不排除能量集中在不含单独闭轨的分形不变集上的情形；那需要别的推广（例如小熵双曲集）。
