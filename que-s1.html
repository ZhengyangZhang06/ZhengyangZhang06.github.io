S1：频率不必完全精确

原定理要求真正的 Laplace 本征函数，频率一点都不能差。S1 证明：只要频率的模糊程度小于 h/log(1/h)，结论 μ(Γγ) ≤ ½ − ε 依然成立。

和原来比，进步在哪里

只改了一个假设：把"精确本征函数"换成"对数拟模"。

-- 定理 A（原来）：精确本征函数
Δ_g u_j = −λ_j² u_j

-- S1：对数拟模（h = 1/λ）
‖Δ_g u_j + λ_j² u_j‖ ≤ δ_j · λ_j / log λ_j,   δ_j → 0
-- 等价地：‖(−h²Δ − 1) u‖ = o(h / log(1/h))

精确本征函数是 δ = 0 的特例，所以 S1 严格强于定理 A。ε 和原来一样：先选曲面和闭测地线，再对所有拟模序列一起成立。

为什么正好是 h/log(1/h)

谱宽（频率模糊度）闭轨质量
0（精确本征函数）≤ ½ − ε（定理 A）
o(h/log(1/h))≤ ½ − ε（S1）
c·h/log(1/h)，c 固定可以 > 0：已知有在双曲闭轨上形成疤痕的例子（Eswarathasan–Nonnenmacher 2017）

证明里用到的所有工具（Egorov 定理、不确定性原理、占据论证）只追踪到 log(1/h) 量级的时间（Ehrenfest 时间）。在这个时间内，谱宽 o(h/log(1/h)) 的状态和精确本征函数的误差累积起来仍然趋于 0；再宽一点就会碰到真实存在的反例。S1 因此把现有方法的边界精确地定在 h/log(1/h)。

为什么它重要

  • 结论是稳健的，不依赖"频率完全精确"这个理想条件。
  • 它是任何"迭代"方案的地基。想把闭轨质量一步步压到 0，每一步操作（比如截取闭轨附近的部分再过滤频率）产生的新状态都不再是精确本征函数，而是窄谱宽的拟模。没有 S1，定理在迭代的第二步就用不上了。

证明的结构

在原证明里，"精确本征"只在三个地方用到。树把根节点拆成了对应的几块：

  1. 谱控制：把拟模条件转成谱展开里的估计，得到传播子的近似相位 ‖U(t)u − e−it/hu‖ = o(|t|/log(1/h))；
  2. 固定时间节点：支撑不变性和固定时间极限的拟模版本；
  3. 对数时间捕获：把"观测统计的时间平移不变性"换成近似版本，误差在对数步数内累积为 o(1)；
  4. 组装：新误差在第一个极限（j → ∞）里就消失，后面的步骤不变，ε 也不变。

不需要新的数学想法，难点是技术细节；最初认为风险最大的谱引理最先被证完。

它不说明什么

  • 上界还是 ½ − ε，没有变小。
  • 它不能推出"增益引理"（"每一步能把疤痕再推高一点"）。在 S1 成立的前提下，增益引理等价于"闭轨质量为 0"，仍是公开问题。
