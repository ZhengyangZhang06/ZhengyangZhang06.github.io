LOT · git workers

LOT Git Workers: machines the tree cannot reach can help proveLOT Git Workers：树连不到的机器也能帮忙证明

A LOT tree can hand some obligations to another machine. The two sides never connect: they share one git repository, and each work order is a branch in it. The tree stays the master, and every proof that comes back must pass the tree's own gate.

LOT 树可以把部分 obligation 交给另一台机器。双方从不直连，只共享一个 git 仓库，每张工单就是其中一个分支。树始终是主控，交回的证明必须通过树自己的 gate。

1 · The idea1 · 基本思路

Locally the controller drives sessions; remotely, all handover goes through git branches.本地由 controller 直接驱动 session；远程时一切交接都通过 git 分支。

no direct connection between tree and worker树与 worker 之间没有直接连接
  • Order = branch lot-orders/<tree>/<obl>-<n> pushed by the tree. Claim = the worker creates lot-claims/…; only the first push wins. Result = lot-results/…. No GitHub issues or PRs.
  • The worker uses its own machine and model, but the same Lean / Mathlib / checker; if the checker's sha256 differs, it refuses the order.
  • Heartbeat every 10 min; 30 min of silence → stale, the obligation goes back to the tree.
  • An order is open for 5 min; if nobody takes it, the tree resumes its own sessions. Off by default.
  • 工单 = 树推送的分支 lot-orders/<tree>/<obl>-<n>。认领 = worker 创建 lot-claims/…，只有第一个 push 成功。结果 = lot-results/…。不用 GitHub issue 或 PR。
  • worker 用自己的机器和模型，但 Lean / Mathlib / checker 必须相同；checker 的 sha256 不一致就拒单。
  • 每 10 分钟一次心跳；30 分钟没有心跳 → stale，obligation 收回给树。
  • 工单只等 5 分钟，没人接就由树恢复自己的 session。默认关闭。
2 · How to start2 · 如何启动
Master (runs the tree)主控端（跑树）

Create a private orders repo with the worker kit on main, invite the collaborator, then:

建一个私有工单仓库，把 worker 套件放在 main，邀请协作者，然后：

ltree run --name putnam-1970-b6-pair ... \
  --param git_workers=hold \
  --param git_remote=https://github.com/<org>/<orders-repo> \
  --param git_worker_model=claude/deepseek-v4.1-flash:max \
  --param git_worker_min_depth=1
Collaborator (runs a worker)协作者（跑 worker）

Clone the orders repo, run bash setup.sh (builds the same toolchain, ~1 h), then start the worker before orders go out:

克隆工单仓库，运行 bash setup.sh（搭建相同工具链，约 1 小时），在工单发出前启动 worker：

WORKER_ID=ziyang-brev-flash bash worker.sh
